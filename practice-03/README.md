## Эксперименты с DOM и событиями

Файл `examples/dom-events.html` открывается по адресу `http://127.0.0.1:5503/examples/dom-events.html`. Запускались все пять экспериментов, поведение совпало с ожиданиями методички:

1. `querySelector("#missing")` возвращает `null`; `querySelectorAll(".missing")` возвращает пустой `NodeList` длины 0, обращение к свойствам без проверки вызовет ошибку.
2. `dataset.taskId` до `Number()` — строка `"23"`, после — число `23`. Строка `"4abc"` превращается в `NaN` — это отсекается проверкой `Number.isSafeInteger`.
3. Повторное нажатие «Добавить запись» увеличивает DOM, но сохранённый `NodeList` остаётся прежней длины — новый запрос `querySelectorAll` возвращает обновлённый снимок.
4. Текст `"<strong>Проверка</strong>"`, выведенный через `textContent`, отображается как есть; HTML-элемент `strong` не создаётся.
5. В журнале видны фазы: 1 — захват, 2 — цель (span), 3 — всплытие к кнопке. `event.target` — span, `event.currentTarget` — кнопка.

## Отладка

Через DevTools (`F12`) точка останова поставлена на строке `const id = Number(card.dataset.taskId);` в `handleTaskListClick`. При клике по кнопке «Удалить» id=4:

- `event.target` — span с классом `.action-label`,
- `event.currentTarget` — `ul#task-list`,
- `button.dataset.action` — `"delete"`,
- `card.dataset.taskId` — `"4"` (строка),
- `id` после `Number()` — `4` (число).

Проверен отказ: в DevTools через панель Elements `data-task-id` одной карточки изменён на `4abc`, затем клик по «Удалить» — задача не удалилась, в `#operation-message` появилось «Некорректный идентификатор задачи».
